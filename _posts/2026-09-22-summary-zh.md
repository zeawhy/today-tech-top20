## [OpenAI 发布 GPT-6 Sol 与 Luna，大幅降价](https://openai.com/index/introducing-gpt-6-sol-and-luna/) ⭐️ 9.0/10

OpenAI 发布了 GPT-6 Sol 和 GPT-6 Luna，即日起在 ChatGPT Work 和 Codex 中面向 Plus、Pro、Business、Enterprise 和 Edu 用户开放。GPT-6 Luna 的价格约为 GPT-5.6 Luna 的一半，GPT-6 Sol 定价为每百万输入/输出 token 2 美元/10 美元，OpenAI 表示推理和缓存方面的改进使其能够在提升能力的同时降低价格。 大幅降价可能重塑 AI 编程和智能体工作流的竞争格局，因为在 OpenAI、Anthropic 等提供商之间，每任务成本往往是决定性因素。运行高并发智能体工作负载的开发者和企业受益最大，这可能促使部分用户从 Claude Opus 等竞品转向 OpenAI。 OpenAI 声称 GPT-6 Sol 和 Luna 在处理任务上明显优于 Anthropic 的顶级模型如 Fable 和 Opus，OpenAI 发言人也向 VentureBeat 确认了定价。GPT-6 Sol（max）在智能水平上处于领先梯队，同时速度高于平均水平且输出较为简洁，但具体基准对比仍存在争议。

## [vLLM v0.30.0 发布：新增 Fast Start GPU 权重缓存与多款新模型支持](https://github.com/vllm-project/vllm/releases/tag/v0.30.0) ⭐️ 8.0/10

vLLM 发布 v0.30.0，包含来自 315 位贡献者的 762 个提交，并引入名为 Fast Start 的常驻式每 GPU 权重缓存守护进程：它将量化后、按张量并行（TP）分片的权重保留在 GPU 显存中，使引擎可通过 CUDA IPC 配合 --load-format ipc_cache 快速重启，而无需从磁盘重新加载。该版本还新增对 DeepSeek-V4.1-Flash、DeepSeek-V4-Flash-Vision-Exp、GLM-5.3-Flash、K2-Horizon、Cohere Compass、Bailing V3 VL 和 Nanbeige4.2 等模型的支持，并加入 Gumbel-max 水印与 HiSparse 主机端 KV 分层。 Fast Start 直接针对 LLM 服务中最痛的环节之一——冷启动与引擎重启缓慢，这对自动扩缩容、Serverless 部署以及生产环境中的频繁模型切换意义重大。广泛的新模型覆盖，加上 PCP+DCP、Elastic EP 等大规模服务特性，使 vLLM 继续稳居最新开源权重模型高吞吐推理引擎的默认选择。 Fast Start 现已覆盖 FP4 检查点和多节点张量并行；该版本还带来 Model Runner V2 的多项改进，例如在 FULL CUDA 图下实现双批次重叠、自适应投机解码验证，以及将图捕获时间从 12 秒降至 2 秒、H200 上引擎初始化从 28.9 秒降至 8.2 秒的优化。量化方面新增通过 quantization_config.targets 实现定向在线量化，并在 SM100/103 上默认以 FlashInfer CuTeDSL NVFP4 W4A16 取代 Marlin。

github · khluu · 9月22日 05:20

**背景**: vLLM 是广泛使用的开源大语言模型推理与服务引擎，以 PagedAttention 和高吞吐批处理著称。在生产环境中，启动或重启引擎通常需要从磁盘加载并重新分片模型权重，对大模型而言可能耗时数分钟；Fast Start 通过将已量化、已按张量并行分片的权重缓存于 GPU 显存并通过 CUDA IPC 映射，从而绕过这一过程。MXFP8 与 NVFP4 是用于压缩模型权重、加速推理的低精度格式（8 位与 4 位浮点），而 FlashMLA 是 DeepSeek 针对多头潜在注意力（MLA）优化的注意力内核库。

## [TypeSafe AI 发布 Jev：一种“系统一”决策模型](https://simonwillison.net/2026/Sep/21/jev/) ⭐️ 8.0/10
