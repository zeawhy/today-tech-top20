## [pgrust：让 Postgres 分析速度提升 300 倍](https://malisper.me/how-we-made-postgres-hundreds-of-times-faster-the-query-engine/) ⭐️ 8.0/10

malisper 的一篇深度文章解释了 pgrust（一个基于 Rust 的 Postgres 查询引擎）如何通过批处理、算子融合和 SIMD 实现分析场景下 300 倍的加速。该项目已在 wasm32 上通过了 PostgreSQL 回归测试套件中的 46,066/46,066 个查询。 这表明 Postgres 分析工作负载有可能实现显著的性能提升，为数据密集型应用提供了更快的替代方案。同时，它也展示了自适应规划和基于 Rust 的数据库引擎的可行性，可能影响未来的数据库开发。 优化包括批处理以减少每行开销、算子融合以避免物化，以及 SIMD 实现数据级并行。作者强调正确性是首要任务，通过形式化验证和差分模糊测试证明了超过 1000 个面向用户的函数与 Postgres 逻辑一致。

hackernews · poly2it · 8月7日 11:00 · [社区讨论](https://news.ycombinator.com/item?id=49208535)

**背景**: PostgreSQL 是一个流行的开源关系型数据库，但其查询引擎在分析工作负载方面不如专门的列式数据库优化。pgrust 是用 Rust 重写 Postgres 的项目，旨在提高性能同时保持兼容性。批处理、算子融合和 SIMD 等技术是现代查询引擎中常见的优化手段，用于减少 CPU 和内存带宽的使用。

## [Datasette 1.0a38 修复混合公共/私有设置中的 SQL 注入漏洞](https://simonwillison.net/2026/Aug/6/datasette/#atom-everything) ⭐️ 8.0/10

Datasette 1.0a38（2026 年 8 月 6 日发布）修复了一个 SQL 注入漏洞，该漏洞可能允许用户访问混合了公共和私有表的数据库中的私有表。此修复也适用于 Datasette 0.65.3。 此安全修复对于提供公共和私有表混合服务的 Datasette 用户至关重要，因为它防止了未经授权读取私有数据。这凸显了在开源数据发布工具中及时修补和负责任披露的重要性。 该漏洞影响那些已禁用 execute-sql 权限但仍可通过公共表执行 SQL 注入攻击的实例。建议管理员在包含私有表的数据库上禁用 execute-sql 权限以缓解该问题。

rss · Simon Willison · 8月6日 18:24

**背景**: Datasette 是一个开源工具，用于将数据发布为交互式网站，并内置权限系统来控制对表的访问。execute-sql 权限控制用户是否可以运行自定义 SQL 查询；当禁用时，用户不应能通过原始 SQL 访问私有表。该漏洞在混合公共/私有表设置中绕过了这一限制。
