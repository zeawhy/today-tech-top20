## [OpenAI 发布 GPT-6.1 Sol，性能接近 GPT-6 Astra 但价格更低](https://techcrunch.com/2026/09/29/openai-launches-gpt-6-1-sol-says-it-nearly-matches-gpt-6-astra-and-costs-less/) ⭐️ 9.0/10

OpenAI 发布了 GPT-6 Sol 的升级版 GPT-6.1 Sol，官方称其在代码编写与调试、文档理解以及多步骤业务工作流等复杂专业任务上相比 GPT-6 Sol 有显著提升，整体能力接近旗舰模型 GPT-6 Astra。该模型定价仅为 Astra 标准价的五分之一，缓存输入每百万 token 0.10 美元，API 标准价为每百万输入 token 2 美元、输出 10 美元，目前已向 Plus、Pro、Business、Enterprise 和 Edu 用户在 ChatGPT Work 与 Codex 中开放，但暂未进入 Chat。 此次发布的重要意义在于，它以远低于旗舰模型的价格提供了接近旗舰的能力，可能大幅降低企业和开发者大规模运行智能体编程与多步骤专业工作流的门槛。同时，这也加剧了前沿模型厂商之间在性价比上的竞争，迫使竞争对手在能力和成本效率上同时跟进。 OpenAI 表示，在最高算力投入下，GPT-6.1 Sol 平均每项任务成本约为 5.47 美元，而 Opus 5.5 为 23.21 美元、Astra 为 23.80 美元，成本降低超过 75%。开发者可通过 API 使用模型 ID gpt-6.1-sol 调用，但该模型尚未在标准 ChatGPT Chat 界面中提供。

## [研究：网页与移动端 AI 聊天代理向追踪器泄露提示词](https://jorgegarciaherrero.com/wp-content/interactivos/20260916-Prompt-like-a-butterfly-sting-like-a-tracker-(clean).pdf) ⭐️ 8.0/10

一项针对网页端和移动端对话式 AI 代理的最新隐私分析发现，9 个网页客户端中有 6 个、8 个安卓应用中有 3 个会将对话衍生的内容（如 URL、标题、提示词或截图）泄露给第三方；即使用户拒绝了所有非必要 Cookie，仍有 80.8%的第三方追踪器保持活跃。 这些发现表明，对话式 AI 的隐私风险不仅限于模型训练，还延伸到日常的广告追踪基础设施，影响所有用这些助手进行敏感或工作相关对话的用户。这也进一步说明，用户不能指望 Cookie 提示条或基于 UUID 的 URL 来保护聊天隐私。 该研究同时覆盖网页客户端和安卓应用，泄露的内容是对话衍生的数据，而不仅仅是通用遥测信息。拒绝 Cookie 后追踪器依然存在，说明现有的同意机制对这些服务基本无效。

hackernews · damaru2 · 9月29日 09:03 · [社区讨论](https://news.ycombinator.com/item?id=49890226)

**背景**: 对话式 AI 代理是指在浏览器或移动应用中运行的聊天助手，例如 ChatGPT、Perplexity 等。第三方追踪器是嵌入网站和应用中的脚本与 SDK，用于为广告和分析目的收集用户行为。UUID 是常被放入 URL 中用于引用会话或对话的唯一标识符，但它并不等同于安全或隐私保障。

## [英国实时人脸识别试点扫描 50 万人，零逮捕](https://www.theguardian.com/technology/2026/sep/29/trial-live-facial-recognition-cameras-london-stations-false-positive) ⭐️ 8.0/10

据《卫报》报道，英国在 16 个火车站部署的实时人脸识别（LFR）摄像头进行了为期六个月的试点，共扫描约 50 万张人脸，但未促成任何逮捕，仅出现一次误报。该结果再次引发争论：这类监控系统相对于其成本和隐私影响，是否真能带来实质性的公共安全价值。 这一结果是全球实时人脸识别争论中的关键现实数据，表明大规模部署可能带来微不足道的执法收益，却让数十万无辜民众接受生物特征扫描。它可能影响英国的政策、警方的采购决策，以及其他国家在监控与公民自由之间的权衡。 唯一的误报意味着系统错误地将某人识别为匹配对象，这是人脸识别的已知风险，可能导致错误拦截或逮捕；在不受控的监控环境中，识别准确率还会下降，并因人口群体不同而存在差异。扫描规模其实不大——大约相当于利物浦街车站两天的客流量——说明摄像头仅在很小一部分时间内处于工作状态。

hackernews · ilamont · 9月29日 11:35 · [社区讨论](https://news.ycombinator.com/item?id=49891480)

**背景**: 实时人脸识别使用 AI 驱动的摄像头实时捕捉人脸图像，并与监视名单数据库比对以识别目标人物。误报是指软件错误地将两个不同的人认定为同一人，而漏报则是未能匹配同一人的两张图像。2018 年的“Gender Shades”等研究表明，错误率会因人口群体而显著不同，深肤色女性的错误率远高于浅肤色男性。

## [Anthropic 发布 Claude Sonnet 5.5：更快更便宜，但最高思考档位存在缺陷](https://simonwillison.net/2026/Sep/28/claude-sonnet-5-5/) ⭐️ 8.0/10

Anthropic 发布了 Claude 5.5 家族的第二款模型 Claude Sonnet 5.5，官方称其运行速度提升 30% 以上，大多数任务的成本最多降低 30%，且价格与 Sonnet 5 持平却在所有基准测试中全面胜出。Simon Willison 的独立测试发现，在“max”思考档位下该模型消耗了 128,000 个 token（花费 1.28 美元）后仍未产出 SVG，重现了此前 Opus 5.5 出现的同一缺陷。 Sonnet 5.5 现已成为 claude.ai 免费层所使用的模型，使 Anthropic 的免费服务能力明显强于使用 Luna 5.6 的 OpenAI ChatGPT 免费层。与此同时，反复出现的 max 档位缺陷也让人质疑最高思考档位是否真的实用，因为它可能在耗尽全部输出预算后仍无法给出结果。 该模型的最大输出 token 上限为 128,000，且无论思考内容是否可见，思考 token 都按输出计费；在“xhigh”档位下，鹈鹕测试仅花费 5.74 美分、耗时 41 秒。Sonnet 5.5 在某些编码任务上几乎与 Opus 5.5 相当，Anthropic 还表示 Haiku 5.5 将在“未来几周内”推出。

## [Cloudflare 推出面向 AI Agent 的 cf 命令行工具](https://blog.cloudflare.com/cloudflare-cf-cli-launch/) ⭐️ 8.0/10

Cloudflare 发布了 cf CLI 的开放测试版，这是一个让开发者和 AI Agent 通过命令行调用 Cloudflare 全部 API 的工具。与覆盖约 280 种操作的现有 Wrangler CLI 不同，cf 由 Cloudflare 的 API Schema 自动生成，覆盖超过 3,000 项 API 操作。 这是迈向自主云管理的重要一步，因为 AI Agent 现在可以通过单一工具发现并执行范围更广的 Cloudflare 操作。它可能改变开发者和 AI/ML 从业者自动化基础设施任务的方式，例如部署 Worker、配置安全策略和管理域名。 cf 以 JSON 作为默认输出，并支持命令搜索和引导，使 Agent 更容易自动发现操作、执行操作并处理结果。Cloudflare 举例称，Agent 可以通过同一工具创建和部署 Worker、监控服务、配置 Access 与 WAF，甚至购买域名。

**背景**: Cloudflare 是一家主要云平台，提供 CDN、DDoS 防护、WAF 以及 Workers 等开发者服务。Wrangler 是其现有的命令行界面，用于构建、测试和部署 Workers 项目，但只覆盖 Cloudflare API 的一部分。新的 cf CLI 由 Cloudflare 的 API Schema 生成，该 Schema 定义了可用的服务和操作，使其能够以机器可读的方式暴露完整的 API 目录。
