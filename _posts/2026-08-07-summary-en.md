It demonstrates effectiveness on CELEBV-HQ video generation and turbulent plasma field digital twins. This addresses the critical problem of estimating rollout error in autoregressive generative models, which is essential for long-horizon video generation and scientific simulations where ground truth is unavailable. The bidirectional training also outperforms specialist models, offering a more efficient and broadly applicable approach for the ML community. The method requires no ensembles, held-out data, or governing equations, only one extra rollout. Training both directions in a single network beats two specialist models in both directions, as shown in the paper.

## [Monodratic: Learned Product-Hash Routing for Sparse Causal Attention](https://www.reddit.com/r/MachineLearning/comments/1vg3jda/monodratic_learned_producthash_routing_for_sparse/) ⭐️ 8.0/10

An independent researcher introduced Monodratic, a sparse causal-attention architecture that uses learned product-hash routing to assign source blocks to bounded posting lists and select a fixed number of remote blocks per query. In synthetic associative-recall tests, it achieved 99.35% mean accuracy with only 2 selected remote blocks out of 5 eligible, and recovered all errors when forcing the target block. This work could make long-context transformers more efficient by replacing dense attention with learned sparse routing, potentially reducing computational cost while preserving accuracy. It offers a novel alternative to fixed sparse masks and may inspire further research in efficient attention mechanisms. The implementation is a stateless [batch, sequence, width] -> attention-delta mixer, leaving normalization and feed-forward layers to the host model. It uses RoPE, bounded causal posting lists, and exact softmax over selected tokens; the packed CPU routing showed a fitted timing exponent of 0.993 from 4,096 to 32,768 tokens, and all learned-route runs reported zero posting overflow.

reddit · r/MachineLearning · /u/dttdrv · Aug 5, 10:28

**Background**: Sparse attention aims to reduce the quadratic cost of standard attention by focusing on a subset of tokens. Learned routing, as opposed to fixed patterns, allows the model to dynamically select relevant tokens, which is crucial for long-context tasks. RoPE (Rotary Position Embedding) encodes token positions via rotations, enabling relative position awareness. Monodratic builds on these ideas by using product hashing to route queries to candidate source blocks.
