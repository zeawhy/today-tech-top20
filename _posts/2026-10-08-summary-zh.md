## [OpenAI 宣称 AI 证明多个重大数学猜想](https://openai.com/index/sharing-ai-progress-in-mathematics/) ⭐️ 10.0/10

OpenAI 发布了由 AI 生成的证明及对多个长期未解数学猜想的进展，其中包括唯一游戏猜想和 Barnette 猜想，并在其 GitHub 数学仓库中公开了预印本。该公告称这些成果是 AI 在数学领域的重大突破。 如果得到验证，解决唯一游戏猜想将重塑计算复杂性理论和近似困难性，迫使教科书重写；而在 Barnette 猜想上的进展也将成为图论领域的里程碑。这表明 AI 系统如今可能对前沿纯数学作出贡献，影响数学、理论计算机科学和算法设计领域的研究者。 这些证明以预印本形式发布在 OpenAI 的 GitHub 仓库（github.com/openai/math）中，其中 Barnette 猜想被列为第 180 号问题，但这些结果尚未得到数学界的正式验证。唯一游戏猜想由 Subhash Khot 于 2002 年提出，涉及唯一游戏近似问题的 NP 困难性，对不可近似性结果具有广泛影响。

hackernews · OfficialTurkey · 10月6日 22:17 · [社区讨论](https://news.ycombinator.com/item?id=49984923)

**背景**: 唯一游戏猜想是计算复杂性理论中的核心未解问题，它断言确定某一类游戏的近似值是 NP 困难的；若该猜想成立，则意味着许多重要的优化问题无法在多项式时间内得到良好近似。Barnette 猜想是一个未解决的图论问题，它断言每个每个顶点有三条边的二部多面体图都具有哈密顿回路。自动定理证明是 AI 的一个子领域，研究用计算机程序证明数学定理，而近年来大语言模型的进展重新激发了人们对 AI 辅助数学的兴趣。

Anthropic 发布了 Claude Haiku 5.5，官方称这是其迄今最便宜、最快、能力最强的小型模型，专为高并发、成本敏感型任务设计。与此同时，Anthropic 还向 Max 和 Team 订阅用户推出每月 API 额度：Max 5x 用户每月获得 100 美元，Max 20x 用户获得 200 美元，Team 订阅用户则可获得最高 500 美元并在成员间共享。 Haiku 5.5 瞄准的是由智能体和自动化流水线驱动的、快速增长的低成本高并发推理市场，在这类场景中，每 token 成本和延迟往往比原始推理能力更重要。附带的 API 额度也模糊了消费者订阅与开发者平台之间的界限，让订阅用户无需额外支付 API 费用即可上线 AI 功能。 定价按提示长度分级：提示在 10 万 token 以内时，输入为每百万 token 0.10 美元、输出为 0.50 美元；超过该阈值后分别涨至 0.50 美元和 2.50 美元——一些开发者认为这一门槛对智能体工作负载而言低得不合理。社区基准测试显示，它比 Haiku 4.5 便宜约 9 倍，同时在数据分析基准上高出约两个等级，并支持从 low 到 max 的多档思考级别。

## [Chrome 从 155 版本起重新支持 JPEG XL](https://developer.chrome.com/blog/jpeg-xl-in-chrome) ⭐️ 8.0/10

Chrome 宣布从 155 版本开始正式提供对 JPEG XL（.jxl）图像格式的解码支持，推翻了此前从 Chromium 中移除 JXL 支持的决定。Chrome for Developers 博客的这篇公告确认，这款最流行的浏览器将重新原生渲染 .jxl 图像。 由于 Chrome 占据浏览器市场的主导份额，其此前不支持 JXL 一直是该格式在网络上普及的最大障碍；重新支持它可能终于让 JPEG XL 与 AVIF、WebP 一起从边缘走向主流。这一变化会影响选择图像格式的网页开发者、协调兼容性的浏览器厂商，以及能更快加载更小、更高质量图片的用户。 根据 Chrome 博客，JPEG XL 比 JPEG 压缩效率高 30-50%，支持无损压缩、内置 HDR，以及现有 JPEG 文件的无损转码。社区评论者指出，AVIF 在高压缩率的有损压缩方面仍有优势，而 JPEG XL 的强项在于其跨有损、无损和 HDR 场景的多功能性，不过解码速度可能较慢。

hackernews · AshleysBrain · 10月7日 11:25 · [社区讨论](https://news.ycombinator.com/item?id=49991227)

**背景**: JPEG XL（JXL）是由联合图像专家组（JPEG）与 Google、Cloudinary 共同开发的一种图像格式，旨在以更好的画质和压缩率超越 PNG、JPEG 2000、GIF 和 WebP。Google 此前曾在 Chromium 110 版本前后决定弃用并移除 JXL 支持，这在开发者社区引发了巨大争议，包括一篇广为流传的文章《The Case Against JPEG XL》。随着 Chrome 重新加入支持、Firefox 据称也准备在稳定版中提供支持，JXL 将从仅 Safari 支持走向覆盖大多数浏览器。

## [论文称 OpenAI 的 Lean 纳维-斯托克斯证明与自然语言证明不符](https://arxiv.org/abs/2610.08144) ⭐️ 8.0/10
